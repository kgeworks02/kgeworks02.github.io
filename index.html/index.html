World Concept — 2030 동묘시장

시장의 모습은 그대로,
사람과 AI의 연결 방식은 달라졌다.

2030년의 동묘시장에도 좁은 골목과 노점, 흥정하는 목소리는 그대로 남아 있다. 달라진 것은 사람들의 곁이다. 상인과 손님 모두 각자의 작은 AI, MCU AI와 함께 시장을 걷는다.

AI는 시세를 알려주고, 재고를 챙기고, 손님 응대를 돕는다. 하지만 물건을 고르고 값을 정하는 건 여전히 사람의 몫이다. 연결은 언제나 선택이어서, AI를 쓰지 않는 사람도 이 시장에서 똑같이 사고판다.

  • 01MCU AI의 보편화누구나 자신만의 작은 AI를 지닌다
  • 02전통 시장과 기술의 공존골목은 그대로, 필요한 곳에만 센서가 스며든다
  • 03AI와 인간의 협력정보는 AI가 건네고, 흥정은 사람이 한다
  • 04새로운 거래 규칙사회적 합의 하에 동의한 만큼만 연결되고, 최종 결정권은 손님이 가져간다

Place Features — 2030 동묘시장

오래된 골목에 스며든 AI,
판단은 여전히 사람의 몫.

  • 01전통성과 미래 기술의 공존오래된 골목과 노점에 소형 AI 기술이 점진적으로 스며든다
  • 02선택적으로 연결되는 상권개인·상점·공공 AI가 독립성을 지키다 필요한 순간에 협력한다
  • 03대면 흥정 중심의 거래 문화상품의 가치만큼 대화와 관계가 거래를 움직인다
  • 04행동과 상황을 인식하는 환경사람·상품·공간의 관찰 가능한 변화를 AI가 분석하고 보조한다
  • 05투명성과 선택권을 존중하는 시장AI 작동 고지, 정보 공유 동의, 분석 거부 — 판단권은 사람에게
  • 06AI 효율성과 인간적 판단의 긴장거래는 편리해져도, 직접 보고 소통하는 능력이 더 중요해진다
