Persona & Problem

페르소나와 해결하고자 하는 문제

Persona

한도윤 (41세) / 빈티지 리셀러

오전에는 구매자로 발품을 팔고, 오후에는 좌판을 여는 판매자이다.

User Pain Points

흥정 과정에서 사용자가 겪는 주요 불편함

  • 01상인의 반응을 정확히 읽기 어려워 타이밍을 놓친다.
  • 02짧은 대화만으로는 상대의 의도를 판단하기 어렵다.
  • 03경험과 감에 의존해 협상 결과가 일정하지 않다.
03

Key Features

제품의 핵심 기능과 작동 원리

대화 분석 기반의 실시간 상황 인식

상인의 말투·억양·태도를 분석해 협상 흐름을 파악합니다.

3단계 진동 힌트 제공

망설임, 긍정 신호, 결심에 가까운 신호를 서로 다른 진동 패턴으로 전달합니다.

사용자 피드백으로 학습

신호가 맞으면 오른쪽, 아니라면 왼쪽 끝을 눌러 AI가 다음 판단에 반영합니다.

05

Use Scenario

제품을 사용하는 상황과 경험의 흐름

01 / 신호 알림 시작

대화는 계속 분석하고 있으며, 버튼을 누르면 분석 결과에 따른 진동 신호 알림을 시작한다.

02 / 타이밍 알림

상황에 맞는 진동 신호를 손목으로 전달받는다.

03 / 신호에 대한 피드백

신호가 맞으면 오른쪽, 아니라면 왼쪽 끝을 눌러 피드백한다.

04 / 좋은 타이밍에 합의

AI의 도움으로 적절한 타이밍에 거래를 마무리한다.
