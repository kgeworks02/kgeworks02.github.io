PERSONA & PROBLEM

김영수 52세 · 남성
동묘시장 단골 방문객
PROBLEM

잘못된 AI 안내 정보가
실제 경험과 구매에 영향을 미친다.

카드 위로 마우스를 움직여 보고, 눌러서 크게 열어 보세요.

  1. PROBLEM 01 / 04

    대기시간 예측 오류

    AI의 대기시간 예측 오류가 이용객의 방문 여부와 이동 경로 결정에 직접적인 영향을 미친다.

  2. PROBLEM 02 / 04

    안내와 실제의 차이

    실제 대기시간과 안내 정보의 차이로 인해 불필요한 시간 낭비와 이동 불편이 발생할 수 있다.

  3. PROBLEM 03 / 04

    서비스 신뢰도 저하

    잘못된 AI 정보가 이용객의 시장 탐색 경험과 서비스 신뢰도에 부정적인 영향을 미친다.

  4. PROBLEM 04 / 04

    이동 결정의 부담

    지나면서도 매장 방문 여부를 고민하고 이동을 결정하는 핵심 단계에 부담감이 커진다.
