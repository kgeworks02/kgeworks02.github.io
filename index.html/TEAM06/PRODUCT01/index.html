02

Persona & Problem

페르소나와 해결하고자 하는 문제

Persona

남성 · 65세 은퇴한 회사원

패션에 관심이 많으며 주 2~3회 동묘시장에 방문한다.

User Pain Points

사용자가 경험하는 문제 상황

  • 01옷을 탈의할 수 없어 질 낮은 서비스에 불편함을 느낀다.
  • 02시장 한복판에서 탈의 및 착의에 한계가 있다.
  • 03지불하는 비용만큼의 서비스를 바란다.
03

Key Features

제품의 핵심 기능과 작동 원리

핵심 기능 01

사용자 자동 인식 및 실행

거울 앞에 서면 별도의 조작 없이 사용자를 인식하고 시스템이 실행됩니다.

핵심 기능 02

의류 인식 및 체형 분석

입고 싶은 옷을 렌즈에 비추면 AI가 의류의 형태와 특징을 분석하고, 체형을 스캔해 착의 데이터를 추출합니다.

핵심 기능 03

AI 가상 착의 시뮬레이션

의류 데이터와 체형 정보를 결합해 딥페이크 기반 AI로 옷을 합성합니다. 갈아입지 않아도 착용 모습을 실시간으로 확인합니다.
